PharmaPulse AI — Pharmaceutical Sales Analytics

Turning pharmaceutical sales data into actionable business insights using Python, SQL, and Power BI.

📌 Overview

PharmaPulse AI is a data analytics project designed to analyze pharmaceutical sales performance, identify business problems, predict potential risks, and recommend data-driven actions.

The project follows three key stages:

Diagnose: Identify sales trends, underperforming products, and regional performance issues.

Predict: Forecast potential sales risks and detect negative trends.

Recommend: Suggest actionable improvements based on analytical findings.

📂 Dataset

The dataset contains pharmaceutical sales information used to explore business performance.

Depending on the available columns, the analysis may include:

Product and sales information

Revenue and units sold

Regional performance

Sales channels

Monthly sales trends

🛠️ Tools & Technologies

Python: Data cleaning, exploratory data analysis (EDA), and forecasting

Pandas & NumPy: Data manipulation and analysis

Matplotlib & Seaborn: Data visualization

SQL: Business queries and performance analysis

PostgreSQL / MySQL / SQL Server: Database management

Power BI: Interactive dashboards and KPI tracking

Gamma: Presentation creation

Excel/CSV: Data storage and inspection

🔄 Project Workflow

Load Data: Import the dataset into Python.

Data Cleaning: Handle missing values, duplicates, inconsistent formats, and data types.

EDA: Explore distributions, trends, relationships, and outliers.

SQL Analysis: Load the cleaned data into a database and run queries to calculate KPIs, monthly sales, product rankings, and regional performance.

Dashboard Development: Build an interactive Power BI dashboard with KPIs, charts, filters, and performance comparisons.

Reporting: Summarize key findings, business implications, and recommendations.

Presentation: Create a concise project presentation using Gamma.

📊 Dashboard Highlights

The dashboard is designed to showcase:

Total revenue and sales performance

Monthly revenue trends and growth

Top- and low-performing products

Regional and channel comparisons

Potential sales risks and areas for investigation

💡 Business Outcomes

The analysis aims to help stakeholders:

Understand where sales performance is changing.

Identify products and regions that need attention.

Anticipate potential risks using forecasts, if implemented.

Prioritize investigations and business actions.

Track improvements using measurable KPIs.
